# Apocalypse Fund — Product Brief

## Vision

Make survival finance manageable in a world gone wrong. Apocalypse Fund gives survivors a simple way to track what's coming in, what's going out, and whether they can afford to stay alive.

## Problem Statement

Survivors are losing track of their resources. They don't know their current balance, can't remember what they spent on bribes last week, and have no way to plan ahead. A simple transaction tracker with category-based filtering would give them the visibility they need.

## Target Users

- **Primary:** Workshop attendees playing the role of a survivor managing camp resources
- **Secondary:** BMAD instructors demonstrating the full delivery workflow

## Goals

1. Allow survivors to log income and expenses quickly
2. Show a real-time balance that reflects all transactions
3. Support filtering by resource category to understand spending patterns
4. Provide a clear, dark-themed UI appropriate for post-apocalyptic conditions

## Success Metrics

- A user can add a transaction in under 10 seconds
- The balance updates immediately after adding a transaction
- Filtering by category shows only relevant transactions
- The app renders without errors on first load with mock data

## Scope

### In Scope (current)
- Transaction list with mock seed data
- Balance display
- Add transaction form
- Category filter

### Planned Extensions (via GitHub board tickets)
- Delete a transaction
- Transaction history persistence (localStorage)
- Bid/auction history log
- Spending summary by category
- Low balance warning alert
- Transaction search

### Out of Scope
- User authentication
- Backend or database
- Multi-user support
- Mobile-specific layout

## Timeline

Driven by workshop schedule — features are implemented incrementally by attendees during each session.
